1. Introduction
This Ontology Professional Development Handbook provides a full training framework for developing Associate, Principal, and Expert Ontologists over a structured two-year period. The program includes foundational skills in BFO, OWL, RDF, SPARQL, Protégé, and ROBOT, as well as advanced topics such as SHACL, release engineering, domain modeling, and ontology architecture.
2. Program Structure
• Associate Ontologist (Junior) – Year 1 Foundations
• Principal Ontologist (Mid-Level) – Year 2 Advanced Skills
• Expert Ontologist (Senior) – Leadership & Architecture
